# 아트·애니메이션·UI 명세

## 자산 상태
- 마노: 서로 다른 5방향 파츠(S, SE, E, NE, N), 좌우 반전 3방향(SW, W, NW), 총 8방향 시트. 반전 방향에서는 광원과 작은 비대칭도 반전된다. 이것은 MVP의 명시적인 절충이다.
- walk 12×8=96, idle 6×8=48, hit 4×8=32, down 8×8=64, 총 240개 셀. 각 128×128.
- 원본 파츠 6개×5방향=30 PNG. 시트 재생을 쓰면 파츠를 런타임에 따로 로드하지 않아도 된다.
- 괴물 3종, 각 정지 PNG와 move/hit/die 시트. 6/3/5 프레임, 각 셀 128.
- 아이콘 16개, 128×128 투명 PNG. 실제 투사체는 ball.png를 작게 쓴다. split_balls.png는 분열 묶음 아이콘이며, 실제 자식탄은 ball.png 개별 객체로 렌더한다.
- 효과 impact/dust 각각 4프레임 시트, 셀 128. 페이드/크기 변화로 만든 프레임이다.
- 바닥 ground.png. UI SVG 8종. UI 글자는 이미지에 굽지 않고 DOM 또는 텍스트 렌더로 표시한다.

## 방향/재생
스크린 좌표 x 오른쪽, y 아래. atan2(dy,dx)를 사용한다. E=0°, SE=45°, S=90°, SW=135°, W=180°, NW=-135°, N=-90°, NE=-45°. 각도 구간 폭 45°. 기존 구간에서 6° 이상 벗어났을 때 바꿔 경계 진동을 막는다.
마노 groundAnchor=[64,115.5]를 월드 위치에 맞춘다. 셀 중심을 월드 위치에 맞추면 발이 떠 보이므로 금지. 원화의 실제 높이는 셀 약 80%다. 논리 화면에서 셀 64px 내외로 표시하여 캐릭터 실높이 약 48~52px를 얻는다. 적은 data/balance.json의 실높이로 맞춘다.
걷기 한 사이클 .72초. 속도 비율로 위상을 진행하되 0.7~1.5배 이내. 방향 전환 시 normalized phase 유지. idle 1.2초, hit .18초, down .55초. hit 동안 이동 로직을 멈추지 않는다. 무적 점멸과 짧은 색상 tint는 런타임 효과. 시트가 이미 있는 hit 상태를 억지로 바꾸지 않아도 된다.
프레임 간 형태를 자동 모핑하지 않는다. 12프레임 보행을 정상 주기로 재생하고 위치 보간으로 부드러움을 얻는다. 방향 전환에서 두 실루엣을 오랫동안 반투명 겹치지 않는다.
모든 시트는 content-aware trim 금지. 셀 좌표 고정. 손상 없이 PNG RGBA와 imageSmoothing을 유지한다.

## 리그를 직접 쓰는 경우
data/mano.json의 rigs 각 항목: size는 512×512 조립캔버스에서 부품 크기, pivot은 정규화 회전중심, joint는 그 pivot의 좌표. z는 drawOrder를 따른다. 전체를 먼저 조립한 뒤 월드 표시 배율 적용. 팔·다리 회전은 ±8~11°, 어깨와 골반 겹침 확보. S/N은 다리 회전 ±4°와 높이 차이로 움직임을 줄인다. 직접 리그 재생도 동일 phase를 유지한다.

## 화면과 UI
논리 360×640. 실제 디바이스는 aspect-fit, 남는 영역은 단색 배경. Safe area를 적용하되 화면 비율을 강제로 늘이지 않는다. 가로 기기는 중앙 세로 뷰포트를 제공한다.
상단 HUD에는 체력/XP, 레벨, 웨이브/남은시간, 재화, 일시정지만. 장비·합성 버튼을 전투 위에 띄우지 않는다.
가상 조이스틱은 하단에서 누른 지점에 생기는 floating 방식. 버튼은 이동용 하나뿐이다. 조이스틱 표현은 hitbox를 막지 않고, UI 밖 입력만 받는다. data/ui.json에 위치/색/반경 참조.
강화 카드: 화면 중앙, 가로로 3개를 좁게 놓지 말고 세로 3장. 이름, 현재 중첩 수, 실제 수치 변화만. 카드 높이 90 내외, 간격12. 선택 전까지 전투 정지. 더블탭/중복선택 방지.
장비: 마노 미리보기, 무기 슬롯 한 칸, 현재 등급/피해, 보유 무기 목록, 출발 버튼. 같은 무기 여러 개를 보유하는 것과 동시 장착은 별개.
결과: 클리어/실패, 도달 웨이브, 처치, 재화, 빌드 요약, 다시 도전/장비로. 클리어에서 상자 1개 지급.
합성: 같은 무기·같은 등급 3개 → 상위 1개. 결과 등급 미리보기와 소비 3개를 표시. 실제 합성 액션은 한 번만 커밋한다.
등급 D/C/B/A/S/SS/SSS/EX 색은 data/ui.json. EX도 무지개 애니메이션 대신 고정 청록 테두리로 가독성 유지.

## 바닥
생성 이미지의 가장자리가 수학적으로 seamless라고 보장되지 않는다. MVP 고정 아레나에서는 단일 ground.png를 전장 전체에 cover로 깔아 이음매를 없앤다. 무한 스크롤 타일맵으로 임의 확장하지 않는다. 필요 시 불투명도 .35~.5를 바탕색 위에 적용해 입자 대비를 낮춘다. 충돌 장애물은 없음.
