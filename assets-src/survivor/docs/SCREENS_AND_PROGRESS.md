# 화면·전투 밖 성장·저장

## 화면 목록과 표시 문구
- 장비: 「마노의 주머니」, 무기 슬롯1개, 「탱탱볼」, 등급, 「장착 중」, 「합성」, 「출발」.
- 전투: LV, WAVE, 남은 초, 체력바/XP바, 재화, 일시정지. 조작 안내는 첫 판 시작 후3초만 작게 표시.
- 강화: 「이번 판의 행운은?」, 「하나를 골라 주세요」, 카드별 이름/아이콘/중첩/현재→다음값.
- 일시정지: 「잠깐 쉬어가기」, 「계속하기」, 「장비로」. 장비로 나갈 때 전투 포기 확인.
- 결과: 「마노가 해냈다!」 또는 「한 번 더 도전할까?」, 챕터/웨이브/처치/재화, 선택 빌드, 「다시 도전」/「장비로」.
- 보상: 「상자 열기」, 획득 무기 등급, 「확인」. 슬롯이 늘어나는 것이 아님.
- 합성: 「같은 무기 3개를 모아 더 높게」, 소비3개와 결과1개. 불충분/EX는 비활성 이유 표시.

## 장비
무기 기본 정의는 data/weapons.json. 무기 인스턴스는 고유 ID, weaponId, grade를 가진다. 전투 시작 시 장착 인스턴스의 등급 피해 배수를 적용하고 전투 스탯을 새 객체로 복사한다. 전투 중 강화는 원본 장비에 누적 저장하지 않는다. 매판 초기화되는 전투 성장과 영구 등급을 혼동하지 않는다.
초기 지급 D 탱탱볼1개. 한 슬롯만 장착. 아직 다른 무기를 구현하지 않았으므로 상자의 무기 종류는 탱탱볼만이며 등급 D90/C9/B1 확률이 무작위 요소다. 실제로 4종 무기가 있다고 표시하지 않는다. 츄르 등은 후속 확장 지점만 준비한다.

## 합성
같은 weaponId, 같은 grade 인스턴스3개를 소모하고 다음 grade1개 생성. D→C→B→A→S→SS→SSS→EX. EX 합성 불가. 비용0은 이번 MVP 기본값. 등급 피해 배수는 progression.json.
장착 중인 인스턴스는 자동 선택하지 않는다. 사용자가 명시적으로 포함했다면 결과 아이템 자동 장착 여부를 표시하고, transaction 내에서 결과로 교체한다. 버튼 연타/새로고침/다중 탭으로 중복 지급되면 안 된다. 수량이 부족하면 기존3개를 먼저 지운 후 실패하는 구조 금지.

## 보상과 저장
챕터 클리어당 상자1개, 실패에는 상자 없음. 재화는 전투 결과 집계 후 획득분 저장하며 이번 MVP에서는 소비처가 없다. 소비처를 새로 지어내지 않는다.
기존 저장소를 지우거나 기존 키를 갈아엎지 않는다. versioned namespace를 새로 쓰되 기존 시스템의 소유권을 확인한다. schemaVersion, inventory, equippedInstanceId, currency, unlockedChapter, lastAwardedRunIds, bestResults를 저장. runId를 발급하고 결과 보상은 idempotent하게 한 번만 지급.
탭 종료 시 진행 중 전투 복구는 MVP 필수 아님: 재접속 시 미완료 판은 종료, 영구 장비/확정 보상은 보존. 시작 화면에 동작을 명확히 해 사용자 진행을 소리 없이 날리지 않는다. 저장 실패(사생활 모드/용량 등)는 플레이를 중단하지 말고 저장되지 않았음을 알린다.

## UI 구현 메모
패널/바/버튼은 data/ui.json의 색과 모서리 값을 적용한 DOM/CSS가 기본. SVG는 참고/작은 버튼/조이스틱용이다. card.svg를 긴 직사각형에 무조건 stretch해 모서리를 찌그러뜨리지 않는다. 글자는 라이브 텍스트로 렌더하며 폰의 한국어 시스템 글꼴을 사용.
