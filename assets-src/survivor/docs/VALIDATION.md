# 완료 기준과 확인 기록

## 이 패키지에서 확인하는 것
- 명시된 PNG/SVG/JSON이 실제 존재하는가.
- 투명 자산에 alpha=0 배경이 있고, 시트 크기가 셀×행/열과 일치하는가.
- 마노8방향의 실제 파츠 조립 외형, 정지와 반대 보행 위상, 밝은 배경/작은 크기에서 확인.
- 프리뷰는 실제 자산에서 합성, 홍보 원화가 아님.
- 미검증: Claude 코드 적용, 실기기 터치, 프레임률, 난이도별 실승률, 게임 저장 트랜잭션.

## Claude 적용 후 필수
1. 조이스틱 어느 각도든 이동, 화면 밖 드래그/손떼기/두 번째 손가락/취소/백그라운드에서도 입력 고착 없음.
2. 대각선 최대 속도는 수평과 동일. 외형 방향만8개이며 이동은8방향으로 제한하지 않음.
3. 걷기 위상을 유지한 방향전환, 발밑 anchor 안정, 프레임 잘림/투명구멍/두 파츠 중복 렌더 없음.
4. 공 첫 명중, 벽 반사, 적 반사, 예산 소모, 수명 종료. 큰 dt에도 적을 관통해 무시하지 않음.
5. 분열 p=0/.25/1/1.25/2의 기대 자식 수와 실제 생성을 확인. 자식은 절대 재분열하지 않음.
6. 삼지선다 안에서는 서로 다른3개, 다음 레벨 같은 옵션 재등장. 상한 옵션 제외. 선택 연타에도 한 번 반영.
7. damage3회=기본×1.3³, haste2회=기본×.85², count2회=3개. 부동소수 오차 허용.
8. XP 초과량 유지, 연속 레벨업, 일시정지와 강화 중 모든 전투 타이머 정지.
9. 챕터 성공/실패/재시작, 결과 보상1회. 재시작은 전투 강화 초기화, 영구 장비 유지.
10. 동일 무기/등급3개만 합성, EX 비활성, 장착아이템 처리, 클릭 연타/리로드에서도 중복 보상 없음.
11. 기존 게임 저장/라우트/메뉴/뉴스 보존.
12. 360×640 논리 화면을 다양한 모바일 크기에 맞춰 HUD와 손가락이 전투를 가리지 않음.

## 난이도 검증
동일 조작 정책으로 최소 세 비교를 수행: (A) 생존/유틸 중심, (B) 골고루 강화, (C) count/damage/haste/split 집중 반복. 개발용 seed와 강제 카드 선택은 사용자 UI에 노출하지 않는다. 일반 모드 추첨은 정해진 가중치대로 유지한다.
자연 추첨 여러 판의 도달 웨이브/선택 기록/사망시간/처치량을 수집. 최소30판은 초기 경향용일 뿐 확정 승률로 주장하지 않는다. C가 B보다 유의미하게 늦게 막히거나 클리어하는지 확인. 평균 빌드도 전부 쉽게 깨면 중후반 난이도 조정, C도 초반에 전부 막히면 난이도/드랍/공 판정부터 조사.

## 성능 검증
실제 Android 브라우저에서 적100~140, 투사체200 조건의 프레임시간 측정. 목표60fps, 낮은 기기에서 장식 축소로30fps 이상 유지 목표. 이는 목표치이며 이미 달성한 측정값이 아니다. 장식만 줄이고 핵심 판정/획득량/강화값은 유지.
