# 전투·복리 성장

## 전장과 판정
MVP 전장은 화면 안 고정 평지. data/balance.json의 bounds 안에서 이동. 시점은 시각적으로 약한 쿼터뷰지만 이동/충돌은 2D 원형 판정이다. 적은 모든 경계 방향에서 고르게 생성하되 플레이어와 60px 미만이면 다른 위치를 선택한다. 생성 0.35초 예고 후 접촉 활성화. 스폰이 아예 막히면 잠깐 대기하고 플레이어 위에 강제 생성하지 않는다.
적은 플레이어 추적, 서로 너무 뭉치지 않게 약한 분리력. 적 140 soft limit에서 생성 타이머를 멈추고 화면 밖에 무한 대기열을 쌓지 않는다. 프레임 적체 후 한 번에 몰아 생성하지 않는다. 모든 속도와 타이머는 초 기준. 물리 fixed-step 또는 delta 제한을 사용한다.
플레이어 hitRadius 9. 접촉 피해 후 .65초 무적. 한 틱에 여러 적이 겹쳐도 동일 이벤트에서 체력을 반복 차감하지 않는다. 체력 0에서는 사망 상태로 잠그고 결과/보상을 한 번만 처리.

## 탱탱볼
슬롯 하나, 가장 가까운 유효 적을 자동 조준. 적이 없으면 발사하지 않는다. 기본 1.1초마다 공 하나, 공 반경4.5px, 속도260px/s, 피해14. 생성 위치는 플레이어 중심에서 적 방향으로 약12px. 같은 표적에 갇혀 즉시 연속 명중하지 않도록 enemyId별 .18초 재충돌 제한을 둔다.
벽 반사: 접촉 법선으로 속도 반전, 경계 안으로 위치 보정. 적 반사: 충돌 법선 기준 반사 후 겹침 밖으로 밀어내기. 동일 프레임 다시 충돌하는 루프 금지. 추가 반사 bounces=2는 첫 명중/접촉 후 최대2회 더 반사할 수 있다는 뜻이다. 반사 예산을 소모했으면 다음 충돌에서 공 제거. 무조건 bounces+1명의 적을 때린다는 뜻은 아니다.
공 수명은 base ttl3.2초에 반사2회당 .3초씩 더하되 최대5.3초. 고속/큰 dt에 적을 통과하지 않도록 swept circle 또는 5px 이하 서브스텝. 공끼리 충돌하지 않음.
멀티볼은 좁은 부채꼴, 최대 발사각60°. 개수 많다고 전방향 완전 방사를 기본으로 바꾸지 않는다. 잔상은 이전 .03~.05초 이동거리만, 저불투명도. 화면 횡단 선 금지.

## 분열
부모 공의 첫 적 명중에서만 한 번 검사. p=splitChance. floor(p)회 확정 분열 + 소수부 확률로1회 추가. 1회에 자식2개, 각각 부모피해45%, 반경75%, 반사1회, 수명1.4초. 자식은 재분열하지 않는다. 벽 명중에서는 분열하지 않는다. 같은 적의 내부에 태어나 즉시 피해가 중복되지 않게 충돌 밖에서 생성하고 해당 적에 짧은 재타격 잠금 적용. 최대 p=2는 두 번 확정 분열(자식4개).

## XP와 삼지선다
처치 시 XP, 30%로 재화1 드랍. 획득 반경 안에서 끌려오며 실제 접촉 시 획득. 화면 파티클 정리 때문에 XP를 잃지 않는다. 드랍이 많아지면 가까운 XP를 합쳐 총량 보존.
레벨업 때 전투 완전 정지. 그 레벨 카드3개는 서로 다르게 가중 추첨. 이전 레벨에 고른 옵션은 다음 레벨 풀에서 빼지 않는다. 선택 한 번에 반드시 수치 반영. damage는 항상 현재값 ×1.30, haste는 현재 간격 ×.85라서 중첩 효과가 실제로 누적된다.
상한에 도달한 옵션은 풀에서 제외한다. 최대 count10, bounces16, split2, 최소간격.15초, radius14, pickupRadius160. health와 damage는 상한 없이 남긴다. 카드에 현재값→선택 후 값을 보여준다. 최대치 도달 후 효력 없는 카드가 다시 등장하면 실패.

## 복리 체감의 근거와 검증
첫 명중 기준 원시 DPS는 damage×count/interval이다. 기본 14/1.1≈12.73. 예를 들어 8선택에서 count2회, damage3회, haste2회, split1회를 고르면 분열 제외 원시 DPS가 3×1.3³÷.85²≈9.12배다. 반사는 추가 명중 기회를, 분열은 추가 피해/범위를 제공하므로 조합의 가치가 달라진다. 이 계산은 적중률과 적 배치, 오버킬을 제외한 이론값이며 실제 승률 증거가 아니다.
평균 운/좋은 운의 벽은 실플레이에서 확인해야 한다. 지정 빌드로 강제 선택한 테스트와 자연 추첨을 나눠 검증한다. 반복 핵심 카드가 붙었는데도 생존/처치 효율이 거의 동일하면 충돌 또는 성장 적용 오류부터 조사한다. 운이 좋을수록 반드시 이기는 조작 불필요 게임으로 만들지는 않는다.

## 웨이브
기본 챕터 6웨이브, 총210초(강화/일시정지 시간 제외). 시간 생존 시 다음 웨이브, 잔여 적은 유지, 체력15회복. 6웨이브 종료 시 챕터 클리어. 보스 원화는 이번 범위에 없으므로 임의 보스/추가 아트 제작으로 MVP를 지연시키지 않는다. 다음 챕터는 HP/접촉피해/스폰 간격을 data 값으로 조정.
1~2웨이브는 적응, 3~4에서 압박, 5~6에서 빌드 차이가 드러나는 초기 목표. 실제로 모든 빌드가 쉽게 깨거나 전부 실패하면 수치를 조정한다. 체력/속도 증가를 동시에 무작정 올려 회피 불가능한 벽을 만들지 않는다.

## 성능
오브젝트 풀, 공간 분할 충돌, 화면 숫자/장식 파티클 개수 제한. 논리 투사체를 몰래 삭제해 성능을 맞추지 않는다. 높은 빌드에서 먼저 잔상과 피해 숫자를 줄인다. 장치 한계로 판정 축소가 필요하면 그 정책과 손실을 보고하고 임의 성능 저하를 숨기지 않는다.
