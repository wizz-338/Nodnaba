# 마노 모바일 액션 로그라이트 — 통합 구현 지시서

## 0. 작업의 성격
사용자가 요청한 최종 목표는 모바일 세로형 플레이어블 MVP다. ChatGPT는 디자인·아트·기획·이 지시서를 담당했다. Claude가 실제 코딩, 기존 프로젝트 적용, 실행, 테스트를 담당한다. 이 패키지는 실행 게임이 아니라 구현용 자산과 명세다. 별도 사이트 생성이나 무단 배포, 기존 게임/저장 데이터 삭제를 하지 않는다. 기존 DEMO 표기·메뉴·뉴스·아티스트 링크·주소는 유지하고 게임 내부를 수정한다. 현재 저장 구조와 게임 라우트부터 조사하고 기존 마노 관찰/마을 기능이 존재하면 그 데이터를 보존한다. 전투를 넣는 과정에서 기존 기능의 제거를 임의로 결정하지 않는다.

## 1. 읽는 순서
1. 이 파일.
2. ART_AND_ANIMATION.md — 실제 파일, 시트 행/열, 방향, 조립 및 UI.
3. COMBAT_AND_GROWTH.md — 판정과 강화.
4. SCREENS_AND_PROGRESS.md — 화면과 장비/합성/저장.
5. VALIDATION.md — 완료 기준.
6. data/*.json — 구체적인 초기 수치와 메타데이터. manifest.json으로 파일 목록 확인.

우선 요구사항과 수치는 구분한다. 이동만/무기 1칸/마노 외형/괴물 적/평지/중복 강화는 확정 요구다. 6웨이브·시간·피해·확률·등급 배수 등은 이번 MVP를 구현 가능하게 만든 초기 제안값이다. 테스트에서 벽의 위치가 어긋나면 원래 철학을 지키며 조정하고 변경 내용을 보고한다. 검증 없이 실제 승률을 주장하지 않는다.

## 2. 핵심 요구사항
- 모바일 9:16. 화면 드래그 가상 조이스틱으로 이동만 조작한다. 조준/공격 자동. 공격 버튼, 대시 버튼 없음.
- 전투 주체는 마노 한 명, 장착 무기 슬롯 하나. 탱탱볼부터 완성한다.
- 비픽셀의 부드러운 2D SD 아트. 캐릭터의 고양이 얼굴 후드, 검정 단발, 크림 배, 빨간 목줄 보존.
- 단순 평지, 적은 괴물. 장식/공원/분수/장애물 과다 금지.
- 이동 좌표는 360도 연속. 외형은 8방향 애니메이션. 전체 그림을 진행 방향 각도로 눕히지 않는다.
- 초반 적응 구간 이후 성장 벽. 같은 핵심 강화가 반복 출현하여 좋은 운으로 평소 못 넘는 구간을 돌파할 수 있어야 한다.
- 짧은 충돌 효과와 짧은 공 잔상만. 거대한 무지개 궤적 금지.

## 3. 실제 아트 적용
권장 경로는 assets/mano/sheets/의 사전 합성된 시트다. 모든 시트 128px 정사각 셀, 행 순서 S, SW, W, NW, N, NE, E, SE. walk 12프레임, idle 6, hit 4, down 8. data/mano.json이 정확한 값의 기준이다. PNG들을 다시 자르거나 생성할 필요 없다. 시트 소스는 동봉된 파츠를 실제 조립해 만든 것이며 손그림 연속 프레임 방식은 아니다.

원한다면 동일 메타의 rigs와 assets/mano/parts를 이용해 런타임 컷아웃 보행으로 교체할 수 있다. 단, 시트와 파츠를 동시에 겹쳐서 렌더하지 않는다. 프레임 시트를 먼저 적용하는 것이 MVP 우선이다.

적 3종은 assets/enemies/*-move/hit/die.png를 사용한다. 이동은 정지 원화에 squash/bob을 적용한 경량 애니메이션이다. 복잡한 사족 보행을 구현한 것으로 과장하지 않는다. 모든 효과의 배경은 투명, 바닥만 불투명이다.

## 4. 구현 구조 제안
기존 프로젝트 구조를 우선 존중하되 다음 역할을 분리한다.
- assets/: 본 패키지의 렌더 자산.
- data/: 무기, 강화, 웨이브, 적, 장비 등급, 렌더 메타.
- scenes/: 장비/전투/강화 모달/결과/합성.
- systems/: 입력, 자동 조준, 무기 행동, 이동/충돌, 드랍/XP, 웨이브, 저장.
- render/: 아틀라스 재생, 카메라/좌표, UI, 효과.
- tests/: 저장/보상 중복/확률/성장/조작 회귀 검증.
무기 행동은 behaviorId 레지스트리로 분리한다. 무기 정의 하나에 공격 방식을 하드코딩하지 않는다. 미래의 츄르는 summon_cats 유형으로 확장할 수 있도록 한다. 아직 구현하지 않은 무기는 장비 목록이나 보상에 노출하지 않는다.

## 5. 입력/상태 전환
BOOT → EQUIPMENT → COMBAT ↔ LEVEL_UP, COMBAT ↔ PAUSE, COMBAT → RESULT → EQUIPMENT. 합성은 EQUIPMENT에서 진입한다. 강화/일시정지 중 전투 시간, 발사, 적, 공, 무적 타이머 모두 정지한다. 모달을 닫을 때 조이스틱 상태를 초기화한다. pointercancel, 포커스 상실, 화면 잠금/백그라운드 전환에서도 입력을 해제한다. 레벨업이 연속으로 가능한 경우 XP를 버리지 않고 다음 선택을 순서대로 연다.

## 6. 완료 보고
구현한 것, 수정한 수치, 테스트 결과, 남은 한계를 짧게 구분해 보고한다. 실제 테스트하지 않은 FPS/승률/터치 경험을 검증 완료로 쓰지 않는다. 사용자에게 새 이미지 제작이나 파일 분리 작업을 떠넘기지 말고 이 패키지를 그대로 사용해 전투 MVP를 완성한다.
