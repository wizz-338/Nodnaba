# Notes for development

## MANO SURVIVOR: mobile and PC

MANO SURVIVOR has two versions on the site, the phone one
(`#/game/mano-survivor`, 9:16) and the PC one (`#/game/mano-survivor-pc`,
16:9, keyboard). They share all the game code, data and the save; only the
layout, input, screen size and backgrounds differ.

**A request for a "마노 서바이벌 패치" that names no platform applies to BOTH
versions.** See `src/survivor/PLATFORMS.md` for what is shared, what is
platform-specific and the patch checklist.
